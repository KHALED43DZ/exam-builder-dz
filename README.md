# 🎓 منشئ الاختبارات - الجزائر

تطبيق ويب تقدمي (PWA) لإنشاء أوراق الاختبارات والفروض وفق المنهج الجزائري.

## 🚀 التشغيل

```bash
npm install
npm run dev
```

## 📦 البناء

```bash
npm run build
```

## ✨ الميزات
- 7 أنواع أسئلة
- WYSIWYG مع معاينة A4 حية
- Offline-First
- إدخال صوتي
- بنك أسئلة + قوالب
- تصدير PDF
